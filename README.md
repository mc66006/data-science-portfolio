# Data Science Portfolio

This public repository contains the three project pages for the portfolio. Open them directly:

- [Proposal 1 — Seattle Rent and Mixed-Income Housing](https://mc66006.github.io/data-science-portfolio/proposal1/)
- [Proposal 2 — College Tuition and Ten-Year Earnings](https://mc66006.github.io/data-science-portfolio/proposal2/)
- [Learning Time and Learning Outcomes](https://mc66006.github.io/data-science-portfolio/learning-time-and-outcomes/)

The matching source files and reproducible analyses are in [`data-science-project`](https://github.com/mc66006/data-science-project).

## Data sources and responsible use

Proposal 1 uses Seattle Open Data rent and housing tables and records their source attribution and redistribution uncertainty. Proposal 2 uses an institution-level extract downloaded from the U.S. Department of Education College Scorecard portal. Learning Time uses a fixed-seed synthetic dataset with no real student records. Each project page documents its source, methods, findings, and limitations.

A project-specific reflection appears at the end of each showcase page.

## Local structure

- `proposal1/` — Seattle rent and mixed-income housing showcase, with four visualizations.
- `proposal2/` — college tuition and earnings showcase, with three visualizations.
- `learning-time-and-outcomes/` — simulation project showcase, with three visualizations.

## Deployment and checks

GitHub Pages is configured from the `main` branch and publishes the three subpages above. Each page contains its research question, visualizations, findings, limitations, status, and source-project link. The portfolio home stays compact and points directly to those three project pages.

## Peer feedback and response

A classmate reviewed the three project pages and recommended adding explanatory text for what each visualization shows and a concluding paragraph at the end of each page. I implemented that feedback in [commit `a1179c6`](https://github.com/mc66006/data-science-portfolio/commit/a1179c6), which adds chart interpretations and evidence-based conclusions to Proposal 1, Proposal 2, and Learning Time and Learning Outcomes.
